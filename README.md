# 数独训练营 · 公共在线数独做题平台

面向公众与数独选手的全题型数独在线解题平台。
支持 18 种数独变体题目在线练习、做题草稿与进度双轨持久化（未登录存浏览器，已登录存 SQLite 数据库）、即时规则说明、防抖自动保存与全套自动化测试保证。

---

## 核心特性

1. **直接做题，即开即玩**
   - 去掉繁琐教程步骤，直接进入题型题库大厅自选题型和难度开始解题。
   - 做题界面内置详尽规则说明与要点提示，支持随时展开/收起，新手也能轻松上手。

2. **多端进度与草稿双轨持久化**
   - **未登录（游客模式）**：进度、草稿、已填格子、笔记和计时自动实时保存至浏览器 LocalStorage。
   - **已登录用户**：支持快捷一键登录或账号密码登录，进度实时同步到后端 SQLite 数据库；登录时自动将游客期间在浏览器的做题记录和草稿合并同步到云端账号。

3. **全题型覆盖与严格质量保证**
   - 覆盖 **18 个数独题型**（入门四/六/九宫，以及对角线、奇偶、杀手、加减、大小数、不等号、温度计、不规则、连续、五六、堡垒、比例、无马等）。
   - 修复了所有变体的生成与求解约束（如不规则宫连通生成、无马马步约束、五六与连续全标出负约束等），并配备 **全套自动化测试套件（`bun test`）**，确保所有题目 100% 规则合规且唯一解。

| | 六宫杀手数独 | 6×6 | 六宫虚线笼内数字和等于提示数且不重复 |
| **阶段 4：高阶挑战** | 六宫无马数独 | 6×6 | 国际象棋马步位置的两格数字不能相同 |

## 技术栈

| 层次 | 技术选型 |
|------|---------|
| **运行时** | [Bun](https://bun.sh) |
| **前端** | React 19、Vite 6、Tailwind CSS 4、React Router 7、Zustand |
| **后端** | Elysia（`src/server`） |
| **数据库** | SQLite + Drizzle ORM（`data/sudoku.db`） |
| **引擎** | 自研全变多数独生成器、约束传播求解器与规则校验器（`src/engine`） |
| **测试** | Bun Test 测试套件（`tests/`） |

## 开发与部署

### 1. 安装依赖
```bash
bun install
```

### 2. 数据库迁移与初始化题库种子
```bash
bun run db:migrate
bun run db:seed
```

### 3. 运行全套测试
```bash
bun test
```

### 4. 启动开发服务器
```bash
# 同时启动后端 API (3000) 与前端 Vite (5173)
bun run dev
```

### 5. 生产构建与启动
```bash
bun run build
bun start
```
